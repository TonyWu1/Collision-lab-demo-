Try it yourself

Run the demo on your computer

The hosted page is read-only. Use the repository to replay all three prepared scenarios or have Bob analyze branches.

Replay the prepared demo

Runs the known sample scenarios and checks their expected outcomes. You need Git and Node.js 20 or later.

  1. Clone the repository and open its folder in a terminal.
  2. Switch to the demo branch.
  3. Run the demo command.
git clone https://github.com/TonyWu1/Collision-lab-demo-.git
cd Collision-lab-demo-
git switch feature/public-demo
npm run demo

The prepared demo intentionally includes integration-test failures that demonstrate the collisions.

Analyze branches with IBM Bob

For Bob to inspect branches and generate fresh verification evidence, open the cloned repository in IBM Bob and switch to Agent mode.

  1. Make sure the two branches are available in the local clone.
  2. Enter this command in Bob’s chat.
  3. Review Bob’s hypothesis, generated test, and test results.
/collision feature/email-auth feature/profile-cache-v2 demo/combined-auth-cache:requirements/authentication-v2.md

To inspect another pair, replace the two branch names. The command analyzes locally; the public website only displays saved reports.
