# IBM Bob task-session evidence

Add the **real task-session summary screenshots** for CollisionLab to this folder before submitting the project.

For each relevant task in IBM Bob IDE:

1. Sign in to the IBM Bob account provided for the hackathon.
2. Open the project task, select its task header, and display the task-session consumption summary.
3. Capture that summary as a clear PNG screenshot.
4. Use a descriptive filename, for example: `collisionlab_task01_branch-analysis.png`.
5. Add the screenshot here and commit it to the repository.

Only add screenshots captured from your actual Bob tasks. Do not place mockups or generated images here. This folder currently contains instructions only; the evidence images still need to be added by the team.
